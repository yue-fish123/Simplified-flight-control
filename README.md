# 简易版飞控

## 描述
1. 该飞控基于stm32g030c8t6单片机开发，陀螺仪采用MPU6050，通信采用JDY-31蓝牙模块，并且通过手机蓝牙调试器进行遥控。    
1. 由于蓝牙遥控的控制范围较小，以及为了减少开发时间，去除了飞机定高功能。
2. 无人机采用有刷电机，电池为1s电池
